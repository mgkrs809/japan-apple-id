## 自己注册日区 ID：免费，但要过三道关

注册本身不要钱，卡人的是细节。苹果的规则时不时调整，今天能走通的方法，过一阵可能就失效。

**第一关：注册入口。**

不要用 App Store 里的“建立新 Apple ID”，那条路会要求你提供当地信用卡。正确做法是用电脑浏览器的无痕模式，或者手机 Safari 的私密浏览、Chrome 的无痕模式，打开 appleid.apple.com，把“国家或地区”选成日本。用无痕模式是为了避免浏览器里已有的国区账号信息干扰验证流程。

**第二关：邮箱和手机验证。**

准备一个没绑过任何区 Apple ID 的新邮箱，Gmail 或 Outlook 都行。验证码收不到是常见情况，换个邮箱重来，或者等几分钟让苹果重新发送，通常能过。

**第三关：付款方式和账单地址。**

账号建好还不能直接用，得先触发一次账户资料补全。退出原来的 ID，登录新注册的日区账号，App Store 会跳到日本区，随便下载一个免费应用，系统会弹出“Review”提示，跟着走：确认国家、同意条款、设置付款方式时选 **None**，然后填日本格式的账单地址。

地址要按日本的都道府县格式填，网上流传的示例是“北海道札幌市北区北12条西四丁目”，邮编 060-8611。填完提交，日区 ID 就能用了。付款方式选 None 的好处是以后可以用日本礼品卡充值，不用绑卡。

## 拿到日区 ID 后怎么登录，顺序错了会锁机

登录本身只有几步，出问题的都是没按顺序来。

**登录 App Store。**

1. 打开 App Store，点右上角头像进入个人中心
2. 拉到最底端，点“退出登录”，先把当前国区 ID 退出来
3. 滑回最上方，输入买到的日区账号和密码
4. 登录成功后商店自动切到日本区，可以搜日区应用了

**只登 App Store，不要登 iCloud。** 这是整篇文章最重要的一句。在“设置”顶部登录 iCloud，设备可能被激活锁锁死，需要原账号密码才能解锁，而你刚改了密码，卖家也帮不上忙。万一误登了，登录后立刻关闭“查找我的 iPhone”。

**改密的正确顺序。**

很多人拿到号第一件事就是改密码，结果卡在验证码上。原因是账号绑的是虚拟手机号，你改完密码，那个号就收不到验证码了，后面再登录会异常。

正确顺序是：

1. 浏览器打开 appleid.apple.com，用买到的账号登录
2. 进“安全”板块，先把自己的手机号添加为受信任号码
3. 验证通过后，再修改密码
4. 最后同步更新密保问题答案

改完之后，这个号才真正由你控制。下载完应用，建议切回自己的主 ID 再打开应用使用，长期挂在别人的账号上有风险。
